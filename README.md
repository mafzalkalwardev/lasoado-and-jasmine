# LASOADO AND JASMINE LLC

Nationwide trucking and logistics website for an Indianapolis OTR carrier.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- GSAP + ScrollTrigger
- FormSubmit.co for quote and contact forms

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Forms

Quote and contact forms POST to `lasoado84@gmail.com` via [FormSubmit](https://formsubmit.co). The first live submission sends a confirmation email that must be approved once.

## Deploy

This project is set up for Vercel. After connecting the GitHub repository, set no extra environment variables for a basic launch.
